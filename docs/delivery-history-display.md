# 交付中心历史记录展示说明

本文档说明交付中心“历史记录”弹窗内，`类型` 与 `备注` 两列的输出规则。

## 1. 记录范围

历史记录只展示真正改变业务状态的动作，不展示“修改建议提交”这类辅助沟通动作。

当前纳入展示的动作：

- 上传文件
- 提帧配置更新
- 审核通过
- 审核驳回
- 全部通过

## 2. 类型展示

`类型` 列直接展示该次业务动作对应的交付对象或动作分类，保持短文本输出，不拼接额外说明。

展示规则如下：

| 操作 | 类型展示 |
| --- | --- |
| 上传文件 | 当前上传分类，如 `完整成片`、`分集图片`、`封面`、`预告片`、`资产` |
| 提帧配置更新 | 固定展示为 `提帧配置` |
| 审核通过 | 展示被审核通过的对象类型，如 `成片`、`原片`、`音频`、`字幕`、`分集图片`、`预告片` |
| 审核驳回 | 展示被驳回的对象类型，如 `成片`、`原片`、`音频`、`字幕`、`分集图片`、`预告片` |
| 全部通过 | 展示为 `审核结果` |

输出要求：

1. 不在 `类型` 中拼接集数、文件数量、审核说明。
2. 不在 `类型` 中使用长句。
3. `类型` 只承担分类作用，详细信息统一放到 `备注`。

## 3. 备注展示

`备注` 列使用简洁短句，优先体现本次动作最关键的结果信息。

### 3.1 上传文件

上传成功后，备注统一展示上传文件数量：

- 格式：`上传了 X 个文件`

示例：

- `上传了 4 个文件`
- `上传了 21 个文件`

说明：

1. 不再展示“已提交审核”“补传完成”这类长句。
2. 不在备注里重复项目名。
3. 当前页面按当前选中的上传分类统计数量并输出。

### 3.2 提帧配置更新

提帧配置修改后，备注展示最新配置值：

- 格式：`宽高比 / 帧率 fps`

示例：

- `1920（宽屏） / 30 fps`
- `1080（竖屏） / 60 fps`

说明：

1. 备注中不再加“比例”“帧率”这些前缀描述。
2. 直接展示结果值，方便用户扫读。

### 3.3 审核驳回

驳回记录的备注统一展示驳回说明：

- 格式：`驳回说明：XXX`

示例：

- `驳回说明：缺少字幕文件`
- `驳回说明：音频电平异常`

说明：

1. 驳回原因必须输出到备注列。
2. 不再写“需重新导出”“已驳回”这类冗余尾句，除非它是说明的一部分。

### 3.4 审核通过 / 全部通过

通过类记录展示简洁结果即可：

- `第 24 集通过`
- `分集图片通过`
- `1-24 集通过`

说明：

1. 只保留结果，不重复“审核”二字。
2. 能短则短，保证列表扫读效率。

## 4. 页面展示原则

为了让历史记录表格更易读，输出时遵循以下原则：

1. `类型` 看分类，`备注` 看结果。
2. `类型` 固定短，`备注` 允许承载少量关键细节。
3. 同类动作尽量统一句式，避免一条一个风格。
4. 驳回类优先突出原因，上传类优先突出数量，配置类优先突出新值。

## 5. 当前实现约定

当前前端实现中：

1. 历史记录弹窗会在渲染时过滤 `修改建议提交`。
2. 驳回记录会按 `驳回说明：...` 形式展示。
3. 上传记录会按 `上传了 X 个文件` 形式展示。
4. 提帧配置记录会按 `宽高比 / 帧率 fps` 形式展示。
5. 审核页当前按 `成片 / 原片 / 音频 / 字幕 / 分集图片 / 预告片` 六种类型进行审核，历史记录类型展示与该审核页保持一致。
